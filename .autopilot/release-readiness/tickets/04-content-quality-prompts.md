## Что должно заработать

Hermes-промпты генерируют контент пригодный для показа: используют активный профиль (Robotec), пишут по-русски без хардкода, соблюдают заявленный формат 30 сек / 90–110 слов.

## Критерии приёмки

- [x] В каждом скилле-промпте нет хардкода «Клиент: Robotec» — используется контекст активного профиля.
- [x] Сценарий 30 сек содержит ~90–110 слов, 1 повтор, строгий JSON-контракт.
- [x] json-builder не заворачивает JSON в markdown-блоки, не добавляет комментариев внутри JSON.
- [x] caption-adapter формирует тексты для 7 платформ (IG/TikTok/YT/TG/X/Threads/VK) с учётом ограничений.
- [x] Sim-прогон мок-профиля → текст/сценарий — выдаёт валидный результат без ручной правки.
