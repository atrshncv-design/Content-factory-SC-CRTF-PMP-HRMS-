# Спека 08 — Онбординг клиента из URL

**Фаза:** P0 · **Статус:** к реализации · **Ключевой демо-момент**

> Это **первое, что видит клиент на переговорах**: ты даёшь заводу один URL его
> сайта → завод сам выводит полный профиль (ниша, тон, аудитория, соцсети,
> конкуренты, готовые темы). Без анкет, без звонков, без ручного ввода.

## 1. Цель

По одному URL сайта клиента за ≤ 1 минуту сформировать в БД запись `client`,
из которой все остальные блоки берут контекст:
- **ниша и отрасль** (для запросов аналитики);
- **целевая аудитория** (B2B/B2C, сегменты, роли);
- **тон и стиль коммуникации** (tone of voice);
- **соцсети клиента** (где он уже есть);
- **список конкурентов** (seed для блока аналитики);
- **готовые темы/форматы** для первого цикла.

## 2. Подход: гибрид, ведущая роль Hermes

Не чистый DOM-парсинг (ломается на разных сайтах) и не чистый LLM (дорого и
слепо), а двухступенчатый конвейер:

```
[URL] ─► [Ступень 1: лёгкий fetch + извлечение] ─► черновик ─►
   [Ступень 2: Hermes-анализатор] ─► профиль клиента ─► [БД]
```

### Ступень 1 — лёгкий пред-fetch (n8n, бесплатно)
1. `HTTP GET <url>` сайта, `/`, `/about`, `/contacts`, `/sitemap.xml`.
2. Из HTML извлечь (регэкспами/Code-нодой):
   - `<title>`, `<meta name="description">`, `<meta og:*>`, `<h1>`;
   - ссылки на соцсети из футера/шапки (паттерны `instagram.com/`,
     `t.me/`, `youtube.com/`, `vk.com/`, `tiktok.com/`, `x.com/`, `facebook.com/`,
     `rutube.ru/`);
   - явные email/телефон (для B2B-контекста);
   - текст ключевых страниц (`/about`, `/services`, `/products`) — обрезанный
     до ~8k символов, чтобы влез в промпт.
3. Если сайт отдаёт редирект/403/JS-only — fallback: `sitemap.xml` + то, что
   удалось вытащить из `<head>`.

> Эта ступень **не пытается понять** контент — она лишь собирает «сырьё».
> Устойчива к разной разметке, т.к. метатеги и соцссылки почти везде одинаковы.

### Ступень 2 — Hermes-анализатор (LLM)
Специальный **субагент-Онбординг** (см. спеку 03, раздел «субагенты» — добавляется
четвёртым, запускается по требованию, не в каждом цикле).

**Вход в промпт:**
- URL клиента.
- Черновик из Ступени 1 (мета, соцссылки, текст about/services).
- (Опц.) текст главной Telegram-канала/соцсети, если нашли ссылку (через
  scrapecreators — топ-5 последних постов).

**Выход — структурированный профиль:**
```json
{
  "client_name": "Robotec",
  "domain": "robotec.ru",
  "industry": "промышленная робототехника",
  "niche_description": "системный интегратор промышленных роботов KUKA под ключ: аудит, ТЭО, подбор, монтаж, пусконаладка, обучение, поддержка 24/7",
  "audience": {
    "type": "B2B",
    "segments": ["автомобилестроение", "машиностроение", "стройматериалы",
                 "пищевая промышленность", "аэрокосмос", "металлургия"],
    "decision_makers": ["владельцы производств", "директора заводов",
                        "главные инженеры", "технологи"]
  },
  "tone": "экспертно-деловой, акцент на ROI и окупаемость 1-2 года, без слэнга",
  "socials_found": [
    {"platform": "telegram", "handle": "@robotec_tg", "url": "https://t.me/robotec_tg"},
    {"platform": "youtube",  "handle": "...", "url": "..."}
  ],
  "competitors_seed": [
    {"name": "KUKA",       "hint": "бренд-партнёр"},
    {"name": "ABB Robotics","hint": "международный конкурент"},
    {"name": "FANUC",      "hint": "международный конкурент"}
  ],
  "suggested_topics": [
    "как робот снижает брак на 40%",
    "окупаемость сварочного робота за 14 месяцев",
    "4 мифа о роботизации",
    "робот-паллетировщик vs 3 грузчика"
  ],
  "suggested_formats": ["demo", "было/стало", "мифы", "обзор оборудования"],
  "confidence": 0.85,
  "gaps": ["не нашёл Instagram — уточнить у клиента"]
}
```

> `confidence` и `gaps` — чтобы в TG показать «что уверенно, что надо подтвердить».

## 3. Поиск соцсетей и конкурентов

### Соцсети клиента
- **Сначала** — из футера сайта (Ступень 1).
- **Если в футере нет** — Hermes инициирует через scrapecreators:
  - `GET /v1/instagram/search/profiles?query=<название компании>`
  - `GET /v1/youtube/search?type=channels&query=<название>`
  - `GET /v1/tiktok/search/users?query=<название>`
- Дедупликация по имени/URL → в `client_socials`.

### Конкуренты
- Hermes в промпте просится «назови 3-5 прямых конкурентов в этой нише» —
  это даёт `competitors_seed` (имена/домены).
- Затем Ступень 1 аналогично парсит **их** сайты для подтверждения соцсетей,
  либо scrapecreators-поиск по именам → реальные хэндлы.
- Запись в `competitors` (`is_seed=1` для ручных/LLM-сидов, `is_seed=0` для
  найденных позже автопоиском аналитика).

## 4. БД — новые таблицы/поля

### `clients` (новая таблица)
```sql
CREATE TABLE clients (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  name          TEXT NOT NULL,
  domain        TEXT,
  industry      TEXT,
  niche         TEXT,
  audience_json TEXT,           -- JSON из профиля
  tone          TEXT,
  profile_json  TEXT,           -- весь ответ Онбординга (на будущее)
  confidence    REAL,
  status        TEXT NOT NULL DEFAULT 'draft',  -- draft | confirmed | active
  created_at    TEXT NOT NULL DEFAULT (datetime('now')),
  onboarded_by  INTEGER REFERENCES users(tg_user_id)
);
```

> В MVP — одна активная запись (`status='active'`). Мульти-тенантность (P2)
> добавит `client_id` во все остальные таблицы. Чтобы не переписывать схему
> сейчас, во всех таблицах (topics, scripts, …) **заранее** добавить колонку
> `client_id INTEGER REFERENCES clients(id)`. На P0 она всегда = 1.

### `client_socials` (новая)
```sql
CREATE TABLE client_socials (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  client_id  INTEGER NOT NULL REFERENCES clients(id),
  platform   TEXT NOT NULL,
  handle     TEXT,
  url        TEXT,
  found_from TEXT,               -- footer | scrapecreators | manual
  UNIQUE(client_id, platform, handle)
);
```

### В `settings` → ссылка на активного клиента
- `active_client_id` = `<id>` (используется оркестратором для контекста).

### `client_id` во всех таблицах (миграция 002)
Добавить `client_id INTEGER NOT NULL DEFAULT 1 REFERENCES clients(id)` в:
`topics, scripts, generations, posts, competitors`. Это задел под P2, на P0
всегда 1.

## 5. n8n-воркфлоу `wf-onboard`

```
[Webhook: POST /internal/onboard {url}]   ← Hermes или TG-команда /onboard
   │
   ├─ [HTTP: GET <url>/]                  ← Ступень 1
   ├─ [HTTP: GET <url>/about]
   ├─ [HTTP: GET <url>/sitemap.xml]       (опц., с retry)
   ├─ [Code: извлечь meta, title, h1, socials, текст]
   │
   ├─ [IF socials найдены]:
   │     └─ [HTTP scrapecreators: топ-5 постов ТГ/IG] (для контекста тона)
   │
   └─ [HTTP → Hermes :8000/internal/onboard-analyze {url, draft}]
                                                       │
   (Hermes формирует профиль, пишет в clients/socials/competitors)
```

## 6. UX в Telegram

Новая команда:
```
/onboard <url>   — запустить онбординг клиента
```

**Сценарий:**
1. Оператор: `/onboard https://robotec.ru`
2. Бот: «🔎 Анализирую robotec.ru… (~30 сек)»
3. Hermes прогоняет wf-onboard → профиль.
4. Бот присылает **карточку профиля** + кнопки:
   ```
   🏢 Robotec (robotec.ru)
   Отрасль: промышленная робототехника
   Аудитория: B2B — директора заводов, главные инженеры
   Тон: экспертно-деловой, ROI
   Соцсети: TG @robotec_tg, YouTube (найдено)
   Конкуренты: KUKA, ABB, FANUC
   Темы на старт: 4 варианта

   Уверенность: 85% · Пробелы: нет Instagram

   [✅ Принять и сделать активным] [✏️ Дополнить] [❌ Заново]
   ```
5. После «Принять» → `clients.status=active`, `settings.active_client_id` обновлён,
   все следующие циклы работают под этим клиентом.

## 7. Демо-кейсы для проверки устойчивости

Чтобы завод не опозорился на переговорах, онбординг должен пережить:
- Сайт на чистом JS (SPA) → fallback на `sitemap.xml` + meta.
- Сайт без футера с соцсетями → scrapecreators-поиск по имени.
- Нестандартная ниша → Hermes ставит низкий `confidence` и флаг `gaps`.
- Зарубежный сайт (EN) → язык профиля определяется по сайту (P0 — RU, в P2 EN).

## 8. Безопасность

- HTTP-запрос к произвольному URL клиента — это **SSRF-риск** (внутренние адреса).
  Защита: в Code-ноде запретить приватные диапазоны (`10/8`, `172.16/12`,
  `192.168/16`, `127/8`, `169.254/16`, `::1`), только публичные домены.
- Таймаут на fetch: 10 сек на страницу, не больше 5 страниц.
- Лимит размера ответа: обрезать до ~200 КБ (защита от гигантских ответов).

## 9. Критерии готовности

1. `/onboard https://robotec.ru` за ≤ 1 мин отдаёт профиль с confidence ≥ 0.7.
2. Ниша/тон/аудитория определены верно (для robotec — промышленная робототехника).
3. Найдены ≥ 1 соцсеть клиента (TG @robotec_tg).
4. Сформирован seed-список 3+ конкурентов.
5. 4+ готовых тем на первый цикл.
6. После «Принять» — следующий `/start_cycle` использует этот профиль.
7. SSRF-защита работает (запрос к `http://localhost` отклонён).
8. На «экзотическом» сайте — не падает, отдаёт профиль с gaps.
