# 10. Режим авто

**Status:** ready-for-agent

Blocked by: 08-scrapecreators,09-postmypost

## Goal

Реализовать автоматический режим: парсинг → выбор топовой темы → сценарий → генерация → автопостинг без верификации.

## Acceptance Criteria

- [ ] Пользователь включает режим авто командой /auto on или кнопкой.
- [ ] Бот по расписанию (или по запуску) вызывает цепочку n8n job handlers.
- [ ] Каждый шаг логируется, пользователю отправляется уведомление о завершении/ошибке.
- [ ] Тесты на оркестрацию job-ов.
