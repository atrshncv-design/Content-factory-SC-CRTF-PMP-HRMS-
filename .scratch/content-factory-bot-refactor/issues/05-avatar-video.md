# 05. Сценарий Видео с аватаром + карусель

**Status:** ready-for-agent

Blocked by: 02-fsm-framework

## Goal

Реализовать карусель стоковых аватаров, выбор аватара, запрос темы и генерацию видео с аватаром.

## Acceptance Criteria

- [ ] Карусель: 20 стоковых аватаров (10M/10F), один аватар = одно сообщение с фото.
- [ ] Кнопки: ✅ Выбрать, ⬅️ Назад, ➡️ Далее, 👤 Мои аватары, 📋 Меню, 🧹 Отмена.
- [ ] Состояние индекса хранится в FSM, а не в callback_data.
- [ ] При выборе аватара бот запрашивает тему и длительность.
- [ ] Бот вызывает n8n job handler avatar_video.
- [ ] Тесты на карусель, граничные случаи индекса, callback routing.
