# 03 — Починить кнопки выбора длительности

Blocked by: 01-button-coverage-test
Status: ready-for-agent

## Что сделать

### 3.1 Исправить callback_data

В нодах:
- `TG uv ask dur`
- `TG sh ask dur`
- `TG avv ask dur`
- `TG DR ask`
- `TG DR wrong`

Заменить:
- `cmd:dur_30` → `dur_30`
- `cmd:dur_60` → `dur_60`
- `cmd:durc_30` → `durc_30`
- `cmd:durc_60` → `durc_60`

### 3.2 Добавить обработку в Parser

Добавить в `Parser` (раздел `parseCommand`) команды:
- `dur_30` → `dur_30`
- `dur_60` → `dur_60`
- `durc_30` → `durc_30`
- `durc_60` → `durc_60`

### 3.3 Добавить обработку в Switch cmd

Добавить в `Switch cmd` правила для `command == dur_30`, `dur_60`, `durc_30`, `durc_60`. Направить их на ту же логику, что и существующие запросы длительности (найти ближайшие Code-ноды, которые устанавливают длительность, например `UV Set dur`, `SH Set dur`, `DR Set dur`, `AVV Set dur` и т.п.).

### 3.4 Кнопки навигации

Убедиться, что во всех пяти нодах уже есть **🧹 Отмена** и **📋 Меню** (если нет — добавить).

## Критерий приёмки

- Нажатие кнопки «30 сек» в любом сценарии не уходит в `unknown`.
- `Switch cmd` маршрутизирует `dur_30`/`dur_60`/`durc_30`/`durc_60` в правильные Code-ноды установки длительности.
- Автотест из тикета 01 проходит.
