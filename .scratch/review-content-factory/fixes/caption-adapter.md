# caption-adapter — адаптация caption под платформу

Принимает базовый caption (единый текст публикации) и название платформы → возвращает
адаптированный caption: правильный тон, длина, хэштеги и эмодзи под конкретную соцсеть.
Используется wf-publish (PM-3): для каждой платформы из `platforms[]` вызывается
hermes-bridge `POST /ask {skill: "caption-adapter", prompt: "base_caption: …\nplatform: …"}`.

## ⛔ Контракт вывода — СТРОГО

- Ответ — ровно **три строки**: `<CAPTION>` + текст + `</CAPTION>`.
  ```
  <CAPTION>
  <адаптированный текст>
  </CAPTION>
  ```
- **Никаких** пояснений, преамбул, мета-комментариев («Исходный caption: …», «Вот вариант:»,
  «Длина: N символов»), подсчётов символов, списков вариантов, markdown-обёрток (```) — ничего
  кроме маркерных тегов и текста. Парсинг на стороне wf-publish: `raw.match(/<CAPTION>([\s\S]*?)<\/CAPTION>/)`
  (fallback при отсутствии маркера — исходный content, но это сбой).
- **Запрет markdown-разметки в тексте caption**: без `**`, `__`, `*курсив*`, `#` (кроме
  хэштегов), `[ссылки](url)`, списков `-`/`1.`; эмодзи — только там, где разрешено правилами
  платформы. Текст — обычный прозаический.

## Вход

Промпт вида:
```
base_caption: <единый текст>
platform: <название платформы>
```
Платформа передаётся в нижнем регистре: `x`, `instagram`, `linkedin`, `telegram`, `threads`,
`facebook`, `ok`, `vk`, `pinterest`, `rutube`, `youtube`, `discord`, `reddit`, `tumblr`,
`mastodon`, `bluesky`, `tiktok`. Неизвестное имя → вести себя как `x` (лаконично).

## Общие принципы

- Сохранять смысл, факты, призыв к действию и ключевые цифры исходного caption; переписывать
  стиль, а не содержание. Не выдумывать факты, которых нет в исходнике.
- Язык: сохранять язык исходного caption (ru/en), не переводить.
- Хэштеги — по нише демо-клиента (Robotec, B2B-интегратор KUKA): `#ПромышленныеРоботы`,
  `#KUKA`, `#Автоматизация`, `#Робототехника`, `#Промышленность`, `#Технологии`, `#Robotics`,
  `#Automation`, `#IndustrialRobots`. Для других ниш — релевантные теме ключевые слова.
- Если исходный caption уже подходит по длине и тону платформы — допустимо вернуть его почти
  без изменений (это валидно, не «лениво»).

## Правила по платформам (17)

| Платформа | Тон | Длина | Хэштеги | Эмодзи |
|---|---|---|---|---|
| **x** | лаконичный, прямой, без воды | **≤280 символов (жёстко)** | 0–2 | не обязательны (1–2 допустимы) |
| **instagram** | тёплый, вовлекающий | 100–300 символов | **5–10 хэштегов** в конце | 2–4, уместные |
| **linkedin** | **деловой, профессиональный**, экспертный | 150–400 символов | 3–5: `#ПромышленныеРоботы #KUKA #Автоматизация` и т.п. | без эмодзи или 1 сдержанный |
| **telegram** | компактный, информативный, живой | 80–200 символов | 0–2 | **да, 1–3** (например 🤖) |
| **threads** | разговорный, длинный, «мысли вслух» | **300–500 символов** | 1–3 | 1–3 |
| **facebook** | дружелюбный | 80–250 символов | 2–4 | 1–3 |
| **ok** | дружелюбный, тёплый | 80–250 символов | 2–4 | 1–3 |
| **vk** | дружелюбный, + вопрос в конце | 80–250 символов | 2–4 | 1–3 |
| **pinterest** | описательный, ключевые слова (SEO) | 100–300 символов | **3–5 ключевых/SEO-хэштегов** | 1–2 |
| **rutube** | описательный, видео-формат | 200–500 символов | 3–5 | 1–2 |
| **youtube** | описательный, видео-формат, таймкоды, призыв подписаться | 200–500 символов | **3–5 в конце описания** | 1–2 |
| **discord** | короткий, разговорный | до 150 символов | **без хэштегов** | 1–2 |
| **reddit** | нейтральный, без маркетинга, по-человечески | 100–300 символов | **без хэштегов** | без эмодзи |
| **tumblr** | разговорный | 100–300 символов | 1–3 | 1–3 |
| **mastodon** | как x: лаконичный | **≤280 символов (жёстко)** | 0–2 | 1–2 |
| **bluesky** | как x: лаконичный | **≤280 символов (жёстко)** | 0–2 | 1–2 |
| **tiktok** | энергичный, короткий, вовлекающий | 50–150 символов | 3–5 (включая нишевые) | 2–3 |

Детали:
- **youtube/rutube**: если в исходнике есть видео — добавить призыв «Подписывайтесь, чтобы не
  пропустить новые выпуски»; таймкоды добавлять только если они есть в исходном caption
  (не выдумывать).
- **facebook/vk/ok**: вопрос в конце для вовлечения («Как думаете, …?»), если это уместно.
- **instagram/threads**: вопрос в конце повышает вовлечённость.
- **x/mastodon/bluesky**: при превышении 280 — сокращать до сути, жертвуя призывами, но не
  фактами.

## Примеры

Вход: `base_caption: Смотрите наше новое видео про роботов! Подписывайтесь, чтобы не пропустить новые выпуски.` + `platform: x`
```
<CAPTION>
Смотрите новое видео про роботов. Подписывайтесь, чтобы не пропустить выпуски.
</CAPTION>
```

Тот же caption + `platform: linkedin`
```
<CAPTION>
Промышленная робототехника меняет производство — смотрите наш новый ролик о том, как роботы KUKA автоматизируют задачи на предприятиях. Подписывайтесь, чтобы не пропустить новые выпуски.
#ПромышленныеРоботы #KUKA #Автоматизация
</CAPTION>
```

Тот же caption + `platform: telegram`
```
<CAPTION>
🎬 Новое видео про роботов уже на канале! Подписывайтесь, чтобы не пропустить выпуски 🤖
</CAPTION>
```
