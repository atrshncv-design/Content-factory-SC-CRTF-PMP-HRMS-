## 2. Решения интервью (зафиксированы, 14.08)

1. После генерации (оба быстрых сценария): видео приходит в чат + кнопки «📤 Опубликовать / 🔁 Перегенерировать / ❌ Отклонить» + «📋 Меню»; публикация — через существующий stage4 (платформы + время + подтверждение).
2. Меню двухуровневое: главное («⚡ Генерация / 📊 Аналитика / 📤 Публикация / ⚙️ Система / 📖 Инструкция») → разделы с кнопками команд и пояснениями.
3. Продвинутый цикл (start_cycle) остаётся в меню (раздел «Генерация») как третий сценарий.
4. URL→видео: после вставки ссылки — кнопки длительности 30 сек (5 кред) / 60 сек (10 кред) / 90 сек (15 кред).
5. Инструкцию пишет агент (текст в §6). Команда `инструкция` + кнопка «📖 Инструкция» в меню; `/help` — синоним.
6. Балансы показываются в меню и на старте + генерация блокируется при остатке creatify < 10 кредитов + запрет генерации стоимостью > 50 кредитов (с понятным сообщением). Балансы ВСЕГДА актуальные (живые GET, бесплатные).

## 3. Цель / НЕ-цели

**Цель:** пользовательские сценарии бота становятся непротиворечивыми: все кнопки работают, из любого места есть путь в меню, инструкция доступна всегда, два главных сценария генерации — в один клик, кредитные остатки актуальны, траты защищены гейтами.

**НЕ-цели (out of scope):**
- Мультипользовательность (whitelist = 1 оператор, хардкод 941296693 не трогаем).
- Авто-детект вставленной ссылки в IDLE без кнопки (только явный вход в сценарий).
- Интерактивный ввод аргументов для вспомогательных команд (creators/creator/asset/product/banner/upload_avatar и т.п.) — кнопки с аргументами показывают пример команды (hint), не запускают мини-диалог.
- Изменение контрактов платных webhook-воркфлоу (wf-creatify-link/submit/shorts) — только чтение/вызов; wf-creatify-shorts получает расширение темы→сценарий (единственное исключение, бесплатное).
- Очереди/ретраи генераций, многопоточность.
- Реальный деплой на сервер — отдельным шагом с явного согласия пользователя (гейт).

### 4.8 Быстрый сценарий «URL → видео» (команда `url2video`, кнопка `cmd:gen_url2video`)
Состояния: `QUICK_URL_AWAIT_LINK` → `QUICK_URL_AWAIT_DUR` → `QUICK_URL_GENERATING`.
1. Вход (из IDLE): «🔗 Пришли ссылку на материал для ролика. Например: https://robotec.ru/news/123» + [🧹 Отмена] [📋 Меню]. state=QUICK_URL_AWAIT_LINK.
2. Ссылка пришла (текст в QUICK_URL_AWAIT_LINK): валидация regex `/^https?:\/\//i`. Невалид: «❌ Это не похоже на ссылку. Пришли URL вида https://…» + [🧹 Отмена] [📋 Меню] (state остаётся). Валид: сохранить url в `sessions.quick_payload` (JSON {url}), «⏱ Длительность ролика: 30 сек — 5 кред · 60 сек — 10 кред · 90 сек — 15 кред. Остаток creatify: {cr}» + [⏱ 30 сек] [⏱ 60 сек] [⏱ 90 сек] [🧹 Отмена] [📋 Меню]. state=QUICK_URL_AWAIT_DUR.
3. Кнопка длительности (`cmd:dur_30/60/90`): гейт кредитов (см. §5). Пройден: «⏳ Создаю ролик из ссылки на {dur} сек (~{cost} кред). Пришлю сюда, как будет готово.» + [🧹 Отмена] [📋 Меню]. state=QUICK_URL_GENERATING.
   Реализация: POST localhost:5678/webhook/factory/creatify-link {url} (создаёт link, 1 кред) → link_id → POST localhost:5678/webhook/factory/creatify-submit с json_payload (контракт INSERT-ноды live-воркфлоу: {link: link_id, name, visual_style, script_style, aspect_ratio 9x16, video_length: dur, language ru, target_platform, model_version, override_script, webhook_url} — СВЕРЯТЬ с live INSERT-нодой wf-creatify-submit; тип webhook-пути — полный `/webhook/factory/...`). Ответ submit → creatify_id/generation_id → готово.
4. Callback creatify → wf-creatify-webhook done-ветка → stage3: видео + [📤 Опубликовать] [🔁 Перегенерировать] [❌ Отклонить] + [📋 Меню]. Публикация — существующий stage4.
5. Отмена в любом состоянии → IDLE (существующая CN-ветка, дополнительно чистит quick_payload).
6. Занятость: вход в сценарий при state != IDLE → «⏳ Сейчас выполняется другой шаг. Заверши его или отправь: отмена» + [🧹 Отмена] [📋 Меню] (state не меняется).

### 4.9 Быстрый сценарий «AI Shorts» (команда `shorts`, кнопка `cmd:gen_shorts`)
Состояния: `QUICK_SHORTS_AWAIT_TOPIC` → `QUICK_SHORTS_GENERATING`.
1. Вход из IDLE: «🎬 Пришли тему для шортса (1–2 предложения). Я разверну её в сценарий и сгенерирую вертикальное видео (5 кред за 30 сек).» + [🧹 Отмена] [📋 Меню]. state=QUICK_SHORTS_AWAIT_TOPIC. `shorts <тема>` с аргументом — сразу шаг 2 (state=QUICK_SHORTS_GENERATING).
2. Тема пришла: гейт (§5). «⏳ Пишу сценарий и генерирую шортс...» + [🧹 Отмена] [📋 Меню]. state=QUICK_SHORTS_GENERATING.
   Реализация: расширение темы→сценарий (hermes-bridge, скилл scriptwriter, БЕСПЛАТНО; если расширение уже делает wf-creatify-shorts по тикету T5b — просто POST {script/topic, aspect_ratio 9:16, style, webhook_url} на localhost:5678/webhook/factory/shorts) → ответ wf-creatify-shorts (sync video_output, если done) → доставка видео sendVideo + [📤 Опубликовать] [🔁 Перегенерировать] [❌ Отклонить] + [📋 Меню].
3. `shorts <url>` (это ссылка, не тема): «🔗 Для ссылок есть сценарий «URL → видео». Нажми кнопку или напиши: url2video» + [📋 Меню]. НЕ отправлять source_video_url в ai_shorts (D8).
4. Перегенерация: повтор шага 2 с той же темой (новая генерация, новая оплата — нажатие = согласие).
5. Отмена/занятость — как §4.8.

### 4.10 Кнопка «📋 Меню» — на ВСЕХ экранах
Каждый TG Send-узел wf-tg-bot (кроме answerCallbackQuery) получает строку с кнопкой «📋 Меню» (callback `cmd:menu`). То же для «Telegram stage3» в wf-creatify-webhook (кнопки publish/regen/reject + меню). Исключений нет: старт, меню, разделы, инструкция, статус, бюджет, темы, ping, ошибки, отказы, busy, no candidates, unknown, cancel, тупики (§4.11) — ВСЕ.

### 4.11 Исправление тупиков и устаревших текстов
- TG topic rejected: «❌ Тема отклонена. Можно запустить цикл заново.» + [🔄 Запустить цикл] [📋 Меню]
- TG script rejected: «❌ Сценарий отклонён. Можно запустить цикл заново.» + [🔄 Запустить цикл] [📋 Меню]

- TG regen: реализовать ПЕРЕГЕНЕРАЦИЮ (повтор submit с тем же request_payload из generations; для quick-сценариев — повтор своего сабмита). Убрать «в mock-режиме недоступна». [📋 Меню] внизу.

- TG unknown: «Не понял. Нажми «📋 Меню» или напиши: меню» + [📋 Меню] (убрать «/help»).
- TG ping: «✅ Бот работает (n8n wf-tg-bot active, webhook).» — убрать «long polling». + [📋 Меню]
- TG generating: «🎬 Видео генерируется... Как только creatify ответит — пришлю ролик.» — убрать «(mock)». + [🧹 Отмена] [📋 Меню]
- TG SC busy / TG no candidates: + [📋 Меню] (тексты сохранить).
- TG help: ЗАМЕНИТЬ на инструкцию §4.7 (help = синоним инструкции).
- TG ob fail / TG onboard profile / TG script fail / TG ET fail / TG AS fail / TG CP refuse и прочие одиночные: + [📋 Меню].

## 5. Кредитные гейты и живые балансы

### 5.1 Живые балансы (заменяют протухший settings.credits_remaining)
- creatify: GET `https://api.creatify.ai/api/remaining_credits/`, заголовки keypair `X-API-ID: {{ $env.CREATIFY_API_ID }}`, `X-API-KEY: {{ $env.CREATIFY_API_KEY }}`, typeVersion 4.5 (pitfall: 4.2/2 не доставляет заголовки), ответ `{remaining_credits: N}` (объект в $json.body — парсить дефенсивно: body → raw → JSON.parse(data)).
- SC: GET `https://api.scrapecreators.com/v1/account/credit-balance`, заголовок `x-api-key` (кред ...001 либо $env), ответ может быть JSON-СТРОКОЙ в $json.data → универсальный парсер: `body.creditCount || raw.creditCount || JSON.parse(raw.data).creditCount` (try/catch).
- Куда: ST-ветка (старт), ST2-ветка (статус), BG-ветка (бюджет), menu-ветка (шапка меню). Каждая ветка — свои 2 HTTP + 1 Code (общие ноды между ветками невозможны — ветки выполняются изолированно).
- BG Format дополнительно: креативный остаток + SC-остаток + сегодня/месяц (из generations) + daily/monthly/floor (из settings) + прогноз.

### 5.2 Гейты генерации (перед любым платным вызовом в быстрых сценариях)
- G1 (баланс): живой GET remaining_credits → если < 10: «⛔ Недостаточно кредитов creatify: {cr}. Нужно минимум 10 для генерации.» + [💰 Бюджет] [📋 Меню]. Поток НЕ продолжается.
