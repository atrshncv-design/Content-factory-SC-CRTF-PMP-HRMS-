## Отдельный вывод: wf-creatify-text (текстовые посты)

**Что делает**: webhook `POST /webhook/factory/script` `{topic, description?, language?='ru', target_audience?, video_length?=30}` → Normalize input (topic обязателен, video_length из [15,30,45,60]) → IF topic ok → GET `/api/remaining_credits/` → Code balance → **гейт `balance >= 50`** → POST `/api/ai_scripts/` **(1 кредит, синхронный: status=done + generated_scripts[] сразу)** `{title, description, language, target_audience, video_length}` → Normalize (`generated_scripts[0].paragraphs` → text; status≠done → `generation_not_ready`) → db-bridge: INSERT topics (client_id=1, status='pending') + INSERT scripts (topic_id=`MAX(id)` по title, full_text, target_length, format_tag='creatify') → Finalize → `{ok:true, script_id (creatify uuid), db_script_id, text, status, credits_used, scripts_count}`. Live-тест 13.08: exec 1832 success, scripts.id=4, 1 кредит.

**mock/real**: **mock-ветки НЕТ** — вызов всегда реальный (Phase-2 дизайн; при плейсхолдер-ключах → 401 от creatify). Гейт 50 = floor-политика.

**ПОДКЛЮЧЁН ЛИ К БОТУ/ПУБЛИКАЦИИ: НЕТ.**
- В wf-tg-bot.json (404 ноды, live-состояние 14.08) **нет ни одного упоминания `factory/script`** (grep по всем parameters; бот вызывает shorts/product/asset/banner/avatar-upload/my-avatars/creatify-link/creatify-submit — script отсутствует). В других воркфлоу и cron — тоже.
- Результат (INSERT scripts) **не связывается с sessions** (client_id=1 хардкод, topic_id по MAX(id), без script_id в сессии оператора) → даже при ручном вызове wf-publish не подхватит текст: publish-флоу тянет контент через `sessions JOIN scripts` (FIX-12), а сессия не знает об этой записи.
- Текстовые посты в продукте идут **другим путём**: wf-tg-bot → hermes-bridge scriptwriter (**бесплатно**) → approve:script → INSERT scripts с привязкой к сессии → publish:gen → wf-publish (content=full_text).

**Вывод**: wf-creatify-text — standalone-утилита (альтернатива LLM за 1 кред), в контур бота и публикации НЕ встроена; для текстовых постов MVP она не требуется и не используется. Риски: 1 кред за каждый прямой вызов вхолостую; хардкод client_id=1 и хрупкий topic_id-subselect (№13); дубли тем при повторе; DEPLOYMENT.md:425 заявляет «retry 3x» — в JSON retry отсутствует (док-дрифт). Рекомендация: либо подключить к боту с привязкой к сессии, либо пометить как legacy/неиспользуемый.
