## Проверено и работает

1. **callback_data (чек-лист п.1)**: 0 сломанных кнопок (`[BROKEN literal callback_data x0]` — ни одной `{{ ... }}` без `=`); 17 expression-кнопок корректны (`={{ 'approve:topic:' + $json.topic_id }}` и т.п., включая новые `publish/regen/reject:gen:{id}` у шортсов — реальный generations.id, не creatify-uuid). Все 25 `[NOROUTE]`-флагов скрипта — ложные срабатывания: Parser маппит `gen_shorts`→`shorts`, `gen_url2video`→`url2video`, `menu_*`→`menu`+`args.section`, `hint_*`→`hint`, `dur_*`→`dur`, `schedule:*`→`schedule`. Switch cb: 13 правил ↔ все callback_data кнопок 1:1, answerQuery перед каждой веткой, fallback `CB answer unknown` (терминал).
2. **esc() Markdown (п.2)**: 55/55 Format-нод содержат эталонную `const esc = s => String(s ?? '').replace(/([_*[\]]`])/g, '\\$1')` (MO Format — байт-эталон, включая новые ST2/GE/PG/TP/SCH Stage4, UV/DU/SH Format-семейство); динамика всегда в esc(), статичные тексты с `_` (upload_avatar, publish_type, mode auto, /start_cycle) — RAW внутри и обёрнуты esc() на рантайме (паттерн T2 «не экранировать дважды»); статичные тексты самих TG-нод не содержат неэкранированного `_`; линтер: 0 находок.
3. **Меню 2 уровня + тупики (п.3)**: Switch cmd out[28] menu → Switch MU section (gen/analytics/publish/system/help + fallback → главное меню); TG menu — 5 кнопок разделов; разделы TG menu gen/analytics/publish/system с командами-хинтами (hint_* → Switch cmd out[30] hint) и прямыми командами; TG instruction (IN-цепь), TG help (HL-цепь, help=синоним инструкции по UX-2); кнопка «📋 Меню» (`cmd:menu`, точное равенство) на 74/74 подчинённых sendMessage-экранах (единственное исключение — корневой TG menu, где она не нужна); тупиков (сообщение без кнопок и без выхода) — 0.
4. **31 TG-команда ↔ Switch cmd (п.4)**: 33 правила Switch cmd (31 команда из tg-commands-31.json + служебные `hint`/`dur` для кнопок), все `string/equals` на `$json.command`, fallback `extra` присутствует; слеш-формы 30/31 (см. находку 1); prefix-формы (onboard/client/creator/audience/…) и ru-формы на месте.
5. **Состояния QUICK_* (п.5)**: полный цикл замкнут. Вход: `url2video` без URL → UV Build ask link → `QUICK_URL_AWAIT_LINK`; URL принят → UV Save url → `QUICK_URL_AWAIT_DUR` (+quick_payload={url}); кнопки dur_30/60/90 → `dur` → DU Parse state (dur_ok) → DU LB creatify → DU Gate (cr<10 → TG du low, cost>50 → TG du cap, cost=5×dur/30) → TG du gen → `QUICK_URL_GENERATING` → creatify-link → submit → ждём callback. AI Shorts: `shorts` без темы → SH Ask update → `QUICK_SHORTS_AWAIT_TOPIC`; тема → SH Topic → SH LB → SH Gate (cost=5×ceil(max(30,ceil(chars/200))/30)) → `QUICK_SHORTS_GENERATING` → ai_shorts → done → INSERT generations + `CYCLE_VIDEO_PENDING` → sendVideo + кнопки publish/regen/reject:gen:{real_id}. Повторный ввод в ожидании: Gate Check → Switch gate → UV Parse url (ссылка) / GD Format (длительность) / GG Format (генерируется) / SH Topic (тема). Отмена: `cmd:cancel` → CN Build — полный сброс в IDLE (state, topic_id, script_id, generation_id, selected_platforms, post_at, quick_payload = NULL) с любого экрана. Реген URL→видео идёт ЧЕРЕЗ гейт (RG answer → DU Check state → DU LB creatify — фикс T4 подтверждён); реген шортсов — `rg_shorts` → SH Topic (общая цепочка). Выход по callback: wf-creatify-webhook done → CYCLE_VIDEO_PENDING + кнопки, failed → IDLE.
